# Projection haul is current holders, not notionals

Tally Room notionals remap 2023 votes onto 2026 boundaries and flip Waitākere, Henderson, Wigram, and Wellington North. This page does not use those flips. National’s electorate haul is who currently holds each seat. Transfer then adds Labour or Green seats winnable on 2023 vote counts. Notionals mix a remap with the 2023 counts the Finder shows, and the two notional sources disagree. Big 2026 boundary changes are marked * as a caveat on how in-play the seat is, not as a new winner.
